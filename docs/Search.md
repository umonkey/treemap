# Tree Search and Data Export

The application provides a robust search capability that allows users and researchers to query the tree database across multiple attributes and export the results for further analysis.

## Search criteria

Users can filter trees using a variety of parameters to pinpoint specific vegetation assets:

- State: filter trees by their current inventory state (e.g., alive, stump, removed).
- Address: search trees by street name, locality, or approximate address.
- Species: query trees matching specific botanical or common species names.
- Measurement: check for the presence or absence of particular measurements or attributes (such as trunk circumference, height, or crown width).
- Data age: filter records based on recency, such as identifying trees with photographs fresher than six months.

## Results presentation

Matching trees are displayed efficiently to support both field work and desk auditing:

- List view: presents search results in an organized list format alongside map markers.
- Quick selection: allows clicking any item in the list to instantly center the map on the tree and inspect its detailed properties.
- Result count: displays the total number of matching records for the current query.

## Data export

Users can export search results for research, reporting, or external processing:

- CSV download: enables downloading the entire search result set in comma-separated values (CSV) format.
- Research utility: provides structured data attributes suitable for statistical analysis, GIS integration, and administrative reporting.
